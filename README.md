## 🚀 Featured Projects

<table>
<tr>
<td width="50%" valign="top">

### [Minerva](https://github.com/AlexisRoe/minerva)
A system to report suspicious emails, enrich them, analyse them and mitigate them, turning each report into a structured, reviewable analysis case. It also offers analytics and a simple e-learning. *Early stage, work in progress.*

<sub>**Tech:** TypeScript, NestJS, React, Python workers, PostgreSQL, Valkey, S3 (Garage), Caddy, Docker</sub>

**Highlight:** A pnpm monorepo with a shared typed job contract between services, so a payload change breaks the build instead of production. An isolated image proxy for rendering email content safely is planned. Parsing and analysis experiments live in a separate [Python lab](https://github.com/AlexisRoe/minerva-experimental-email-parser-and-analyser).

</td>
<td width="50%" valign="top">

### [Ledgerly-Rust](https://github.com/AlexisRoe/Ledgerly-Rust)
An expense-approval REST backend, rewritten from [Java/Spring Boot](https://github.com/AlexisRoe/Ledgerly-Java) as a drop-in Rust replacement. ([Live demo](https://ledgerly-rust.a-roehrling.workers.dev/))

<sub>**Tech:** Rust, axum, sqlx, tokio, PostgreSQL, Docker</sub>

**Highlight:** Security by design (typed IDs, secrets that can't be logged, team-scoped queries, an SSRF architecture test, malware scanning of uploads, no `unwrap`/`panic!` outside tests). Both versions pass the same black-box parity test suite. Comes with a 128-lesson *Rust for TypeScript developers* course.

</td>
</tr>
